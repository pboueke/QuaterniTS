## What this is

A headless TypeScript library that generates and validates legal moves, holds a
position and reports game state for the four-player 12 × 12 game. It is intended
for applications **and** for the education and research of the game's rules.

## What this is not

<Card>
  <ul>
    <li>
      <strong>Bounded rules, not a complete engine.</strong> Supported outcomes
      are reported; an unresolved rule edge fails closed rather than inventing a
      result. Read the <a href="/QuaterniTS/scope/">supported scope</a>.
    </li>
    <li>
      <strong>No notation compatibility.</strong> Long coordinates in, typed
      event records out; there is no FEN, PGN or SAN support.
    </li>
    <li>
      <strong>Not a game UI.</strong> This site documents the library; the
      library ships no board, server, clock, opponent or AI.
    </li>
  </ul>
</Card>

## An explicit rule boundary

When a checked controller has an apparent defence but no safe move after a
mate and army-transfer cascade, the library rejects the unresolved action with
`UnresolvedAdjudicationError` **without changing the game**. This software error
is not a mate, pass or draw. The official outcome remains unknown; the
[supported scope](/QuaterniTS/scope/) explains the bounded contract and links
to a concrete position.
