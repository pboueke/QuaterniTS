## What this is

A headless TypeScript library that generates and validates legal moves, holds a
position and reports game state for the four-player 12 × 12 game. It is intended
for applications **and** for the education and research of the game's rules.

## What this is not

<Card>
  <ul>
    <li>
      <strong>Not a complete engine.</strong> Only the outcomes the rules
      authorize are reported, and one provisional rule edge fails closed. Read
      the <a href="/QuaterniTS/scope/">honest limits</a> before relying on it.
    </li>
    <li>
      <strong>No notation compatibility.</strong> Long coordinates in, typed
      event records out; there is no FEN, PGN or SAN support.
    </li>
    <li>
      <strong>Not a game UI.</strong> This site documents the library; the
      library ships no board, server, clock, opponent or AI.
    </li>
  </ul>
</Card>

## Honest limits

- **Not a complete engine.** A lone active controller wins, and a
  two-active-controller stalemate or an accepted draw offer is a draw;
  everything else stays `in-progress` instead of adjudicating a mate that no
  action produced.
- **One provisional rule edge is open.** A checked controller with internal
  defensive moves but no safe publicly committable move has no official outcome;
  only that edge fails closed with `UnresolvedAdjudicationError`. See
  [honest limits](/QuaterniTS/scope/).
